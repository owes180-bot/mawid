# موعد — نسخة الآيفون (PWA)

هذه نسخة ويب من التطبيق تُثبَّت على الشاشة الرئيسية للآيفون. تفتح على تبويب **استكشف**: خلاصة عمودية بأسلوب تيك توك — كل شاشة عمل واحد يشتغل تريلره تلقائيًا (بدون صوت؛ اضغط الشاشة أو زر الصوت لتشغيله)، مع شعاره وقصته تحت، واسحب للأعلى للعمل التالي. نقرتان على الشاشة = إضافة للمفضلة.

تُثبَّت على الشاشة الرئيسية للآيفون وتعمل كتطبيق مستقل (بدون شريط Safari) وتعمل بدون إنترنت بعد أول فتح. نفس التصميم والمزايا: العدّاد التنازلي، التقويم الهجري/الميلادي، المفضلة والتقييم، التريلر، الشعارات، طاقم العمل، صور الألعاب، عربي/إنجليزي.

المجلد `iphone` (أو الملف `Mawid-iPhone-PWA.zip`) يحتوي التطبيق كاملًا كملفات ثابتة. آبل لا تسمح بتثبيت التطبيقات من ملف مباشرة، فيلزم رفع المجلد مرة واحدة على أي استضافة مجانية بـ HTTPS ثم فتح الرابط من الآيفون. أسهل طريقة: **GitHub Pages** (مجاني، 5 دقائق):

## 1) رفع الملفات على GitHub Pages

1. أنشئ حسابًا في <https://github.com> (إن لم يكن عندك).
2. اضغط **New repository** ← الاسم `mawid` ← اختر **Public** ← **Create repository**.
3. في صفحة المستودع اضغط **uploading an existing file** (أو Add file ← Upload files).
4. افتح مجلد `Downloads\Mawid\iphone` على الكمبيوتر، حدّد **كل** ما بداخله (الملفات + مجلدي `fonts` و`icons`) واسحبها إلى صفحة الرفع ← **Commit changes**.
5. من أعلى المستودع: **Settings** ← **Pages** ← تحت Build and deployment اختر **Deploy from a branch** ← Branch: **main** و **/ (root)** ← **Save**.
6. بعد دقيقة أو دقيقتين يظهر الرابط بالأعلى: `https://اسمك.github.io/mawid/`

بدائل تعمل بنفس الطريقة: Cloudflare Pages أو Netlify (رفع المجلد بالسحب والإفلات).

## 2) التثبيت على الآيفون

1. افتح الرابط في **Safari** (وليس Chrome).
2. اضغط زر **المشاركة** (المربع والسهم للأعلى) ← **إضافة إلى الشاشة الرئيسية** ← **إضافة**.
3. افتح «موعد» من الشاشة الرئيسية. أول مرة يحمّل نفسه، وبعدها يشتغل حتى بدون إنترنت.
4. الإعدادات ← مصادر البيانات ← الصق مفتاحي TMDB وRAWG (نفس مفاتيح نسخة الكمبيوتر) ← حفظ.

لنقل المفضلة والتقييمات من الكمبيوتر: في نسخة الكمبيوتر **الإعدادات ← تصدير**، أرسل الملف لجوالك (AirDrop/واتساب/بريد)، ثم في الآيفون **الإعدادات ← استيراد**.

## الفروقات عن نسخة الكمبيوتر

- الإشعارات: iOS لا يسمح للتطبيقات المثبّتة من Safari بإشعارات مجدولة محليًا، فاستخدم «إضافة للتقويم» لأي عمل أو صدّر المفضلة كاملة — تقويم الآيفون يذكّرك قبل الصدور بيوم.
- صور الألعاب تأتي من RAWG فقط (متجر Steam لا يسمح بالوصول من المتصفح).
- المفاتيح والمفضلة تُحفظ داخل الآيفون فقط (لا يوجد خادم ولا مزامنة).

## التحديث لاحقًا

عندما تصلك نسخة جديدة من المجلد، ارفع الملفات الجديدة إلى نفس المستودع (Upload files ← استبدال) وسيحدّث التطبيق نفسه عند فتحه.
